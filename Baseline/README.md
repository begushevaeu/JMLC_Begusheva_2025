# Baseline Models

Эта папка содержит набор базовых моделей машинного обучения (XGBoost и LightGBM), как в чистом, так и в модифицированном виде с добавлением графовых признаков (Graph-based Feature Processing, GFP). Они используются для сравнения с более сложной графовой нейронной сетью (GNN).

## Цель

Цель baseline — предоставить сильные классические ML-бенчмарки, чтобы оценить вклад GNN-архитектуры.

Модели:
- `XGBoost_model.py` — XGBoost без графовых признаков
- `XGBoost_Graph_model.py` — XGBoost с графовыми признаками (GFP)
- `LightGBM_model.py` — LightGBM без графовых признаков
- `LightGBM_Graph_model.py` — LightGBM с графовыми признаками (GFP)

## Метрики оценки

- **ROC-AUC**, **PR-AUC** — основные метрики (важны при дисбалансе классов)
- **Precision**, **Recall** — для анализа ложных/пропущенных алертов
- **F1-score** — для оценки общего баланса

### Целевые значения:

| Метрика    | Минимум | Цель |
|------------|---------|------|
| ROC-AUC    | 0.65    | 0.75 |
| F1-score   | —       | 0.60 |

## EDA

Файл `EDA.ipynb` включает:
- Структурный анализ данных
- Использование графов (через NetworkX) для анализа связей

## Визуализация типов отмывания

Скрипт `Visualization_of_laundering_types.py`:
- Визуализирует распределение переменной `Laundering_type`
- Позволяет проанализировать частоту и структуру категорий

## Модели

Сохранённые модели:
- `xgboost_model.pkl`, `lightgbm_model.pkl` — без графовых признаков
- `xgboost_gfp_model.pkl`, `lightgbm_gfp_model.pkl` — с графовыми признаками

## Использование

Каждый файл `.py` можно запустить как модуль или импортировать в основной pipeline.
