# Baseline Models

Эта папка содержит набор базовых моделей машинного обучения (XGBoost и LightGBM), как в чистом, так и в модифицированном виде с добавлением графовых признаков (Graph-based Feature Processing, GFP). Они используются для сравнения с более сложной графовой нейронной сетью (GNN).

## Цель

Цель baseline — предоставить сильные классические ML-бенчмарки, чтобы оценить вклад GNN-архитектуры.

### Используемые методы и модели

- **XGBoost (Extreme Gradient Boosting)** — это высокопроизводительная реализация градиентного бустинга. Модель последовательно строит деревья решений, где каждое новое дерево исправляет ошибки предыдущего.

- **LightGBM (Light Gradient Boosting Machine)** — еще один фреймворк градиентного бустинга, который отличается высокой скоростью обучения и меньшим потреблением памяти. В отличие от XGBoost, он использует "листовой" (leaf-wise) рост деревьев, что часто приводит к лучшей точности.

- **GFP (Graph-based Feature Processing)** — это метод инженерии признаков, при котором для создания новых фичей используются свойства графа данных. В контексте транзакций это могут быть такие признаки, как количество входящих/исходящих переводов для счета, его центральность в графе или принадлежность к определенному "сообществу". Это помогает выявлять сложные взаимосвязи, невидимые в исходных табличных данных.

### Скрипты моделей

- [`XGBoost_model.py`](./XGBoost_model.py) — XGBoost без графовых признаков
- [`XGBoost_Graph_model.py`](./XGBoost_Graph_model.py) — XGBoost с графовыми признаками (GFP)
- [`LightGBM_model.py`](./LightGBM_model.py) — LightGBM без графовых признаков
- [`LightGBM_Graph_model.py`](./LightGBM_Graph_model.py) — LightGBM с графовыми признаками (GFP)

## Метрики оценки

- **ROC-AUC**, **PR-AUC** — основные метрики (важны при дисбалансе классов)
- **Precision**, **Recall** — для анализа ложных/пропущенных алертов
- **F1-score** — для оценки общего баланса
