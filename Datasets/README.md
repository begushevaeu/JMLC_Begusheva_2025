# Datasets

Этот каталог содержит наборы данных, используемые в проекте **ShAMLock**.

## Файлы

-   `SAML-D.csv`: Исходный синтетический набор данных. Содержит транзакции с разметкой о мошенничестве.

**Источник**: https://www.kaggle.com/datasets/berkanoztas/synthetic-transaction-monitoring-dataset-aml?utm_source=chatgpt.com

-   `df_baseline.csv`: Набор данных, используемый как для обучения и оценки baseline-моделей (XGBoost, LightGBM), так и для обучения GNN-модели.

-   `test_predictions.csv`: Набор данных, содержащий транзакции из тестовой выборки с добавлением двух колонок: предсказание модели («Алерт»/«Не алерт») и вероятность принадлежности транзакции к алерту.
