# Артефакты модели ShAMLock

Эта директория содержит всю информацию об обученной модели ShAMLock (Graph Neural Network), разработанной для обнаружения отмывания денег в рамках этого проекта.

---

## Содержимое

Ниже приведено описание каждого файла и поддиректории:

### Модель
- [`shamlock_best_model.pth`](./shamlock_best_model.pth): Сохраненный `state_dict` обученной модели PyTorch (`EdgeClassifierSAGE`). Этот файл содержит веса обученной модели.
- [`best_threshold.pkl`](./best_threshold.pkl): Число с плавающей точкой, представляющее оптимальный порог классификации, вычисленный на валидационной выборке для максимизации целевой метрики F1-score.

### Объекты для предобработки
- [`node_features.pkl`](./node_features.pkl): Pandas DataFrame, содержащий предварительно рассчитанные и отмасштабированные признаки-'паспорта' для каждого узла (аккаунта) в графе.
- [`account_to_id.pkl`](./account_to_id.pkl): Словарь Python, сопоставляющий уникальные идентификаторы счетов с их целочисленными индексами, используемыми в графе.
- [`edge_encoder.pkl`](./edge_encoder.pkl): Объект `sklearn.preprocessing.OneHotEncoder`, обученный на тренировочных данных для преобразования категориальных признаков ребер.
- [`edge_scaler.pkl`](./edge_scaler.pkl): Объект `sklearn.preprocessing.StandardScaler`, обученный на тренировочных данных для масштабирования числовых признаков ребер.
- [`node_scaler.pkl`](./node_scaler.pkl): Объект `sklearn.preprocessing.StandardScaler`, обученный на тренировочных данных для масштабирования признаков-'паспортов' узлов.

### Индексы данных
- `indices/`: Эта поддиректория содержит индексы разделения данных для обеспечения воспроизводимости.
  - `train_idx.pkl`: Индексы для тренировочной выборки.
  - `val_idx.pkl`: Индексы для валидационной выборки.
  - `test_idx.pkl`: Индексы для тестовой выборки. Крайне важен для идентификации точных транзакций, которые должны быть загружены в базу данных скриптом `seed.py`.

---

### Код и ноутбуки
- [`shamlock-model-kaggle.ipynb`](./shamlock-model-kaggle.ipynb): Основной Jupyter-ноутбук, содержащий полный цикл разработки модели: от загрузки данных и предобработки до обучения, оценки и сохранения артефактов.
- [`data_preparator.py`](./data_preparator.py): Скрипт для подготовки данных для модели.
- [`verify_results.py`](./verify_results.py): Скрипт для верификации и анализа предсказаний модели.
