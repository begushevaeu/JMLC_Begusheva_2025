# Артефакты модели ShAMLock

Эта директория содержит все необходимые артефакты для модели ShAMLock (Graph Neural Network), разработанной для обнаружения отмывания денег. Эти файлы необходимы для запуска предсказаний на новых данных и воспроизведения финальных результатов.

---

## Содержимое

Ниже приведено описание каждого файла и поддиректории:

### Модель
- `shamlock_best_model.pth`: Сохраненный `state_dict` обученной модели PyTorch (`EdgeClassifierSAGE`). Этот файл содержит выученные веса.
- `best_threshold.pkl`: Число с плавающей точкой, представляющее оптимальный порог классификации (например, `0.58`), вычисленный на валидационной выборке для максимизации F1-score.

### Объекты для предобработки
- `node_features.pkl`: Pandas DataFrame, содержащий предварительно рассчитанные и отмасштабированные признаки-'паспорта' для каждого узла (счета) в графе.
- `account_to_id.pkl`: Словарь Python, сопоставляющий уникальные идентификаторы счетов с их целочисленными индексами, используемыми в графе.
- `edge_encoder.pkl`: Объект `sklearn.preprocessing.OneHotEncoder`, обученный на тренировочных данных для преобразования категориальных признаков ребер.
- `edge_scaler.pkl`: Объект `sklearn.preprocessing.StandardScaler`, обученный на тренировочных данных для масштабирования числовых признаков ребер.
- `node_scaler.pkl`: Объект `sklearn.preprocessing.StandardScaler`, обученный на тренировочных данных для масштабирования признаков-'паспортов' узлов.

### Индексы данных
- `indices/`: Эта поддиректория содержит индексы разделения данных для обеспечения воспроизводимости.
  - `train_idx.pkl`: Индексы для тренировочной выборки.
  - `val_idx.pkl`: Индексы для валидационной выборки.
  - `test_idx.pkl`: Индексы для тестовой выборки. Крайне важен для идентификации точных транзакций, которые должны быть загружены в базу данных скриптом `init_db.py`.

---

## Использование

Эти артефакты используются скриптами в директории `PostgreSQL/`:

1.  **`init_db.py`**: Использует `indices/test_idx.pkl` для загрузки корректных тестовых транзакций в базу данных.
2.  **`upload_predictions.py`**: Загружает модель, все объекты для предобработки и порог для генерации предсказаний на тестовых данных и их последующей загрузки в базу данных.
