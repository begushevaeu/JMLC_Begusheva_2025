# FastAPI Backend API (app)

Этот каталог содержит исходный код для бэкенд-сервиса проекта **ShAMLock**, построенного на FastAPI.

## Архитектура

Сервис представляет собой REST API, которое выполняет следующие задачи:
-   Управляет транзакциями (создание, получение).
-   Взаимодействует с моделью машинного обучения для оценки рисков.
-   Работает с двумя базами данных: **PostgreSQL** для транзакционных данных и **Neo4j** для графовых представлений.
-   Предоставляет эндпоинты для дашборда и других клиентов.

## Структура каталога

-   `main.py`: Главный файл приложения. Инициализирует FastAPI, подключает роутеры и middleware.
-   `/routers`: Каталог с файлами, определяющими API эндпоинты (например, для транзакций, алертов).
-   `models.py`: Определения моделей данных для SQLAlchemy ORM (таблицы в PostgreSQL).
-   `schemas.py`: Pydantic-схемы для валидации данных в запросах и ответах API.
-   `crud.py`: Функции для выполнения CRUD-операций (Create, Read, Update, Delete) с базой данных PostgreSQL.
-   `database.py`: Настройка подключения к базе данных PostgreSQL (engine, session).
-   `config.py`: Управление конфигурацией приложения.
-   `neo4j_utils.py` / `neo4j_graph.py`: Утилиты и функции для работы с графовой базой данных Neo4j.
-   `seed.py` / `seed_neo4j.py`: Скрипты для начального заполнения баз данных (PostgreSQL и Neo4j).
