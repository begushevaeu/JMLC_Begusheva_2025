# ShAMLock: Сервис для борьбы с отмыванием денег (AML)

Этот проект представляет собой MVP (Minimum Viable Product) AML-сервиса, который использует графовые нейронные сети (GNN) для обнаружения подозрительных транзакций.

## Доменная модель

В основе сервиса лежит простая доменная модель, состоящая из трех ключевых сущностей:

### 1. Счёт (`Account`)
Представляет собой банковский счёт пользователя.
- `id` (int): Уникальный идентификатор счёта (Primary Key).
- `balance` (float): Текущий баланс на счёте.

### 2. Транзакция (`Transaction`)
Запись об операции перевода средств между счетами.
- `id` (int): Уникальный идентификатор транзакции (Primary Key).
- `from_account_id` (int): ID счёта отправителя (Foreign Key к `Account`).
- `to_account_id` (int): ID счёта получателя (Foreign Key к `Account`).
- `amount` (float): Сумма транзакции.
- `timestamp` (datetime): Дата и время совершения транзакции.

### 3. Оповещение (`Alert`)
Сигнал, который генерируется системой при обнаружении подозрительной транзакции.
- `id` (int): Уникальный идентификатор оповещения (Primary Key).
- `transaction_id` (int): ID транзакции, вызвавшей подозрение (Foreign Key к `Transaction`).
- `risk_score` (float): Оценка уровня риска, присвоенная моделью (например, от 0 до 1).
- `timestamp` (datetime): Дата и время создания оповещения.
