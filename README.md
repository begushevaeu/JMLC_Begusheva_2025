# ShAMLock: Система выявления мошеннических транзакций с помощью графовых нейронных сетей (GraphSAGE)

> **Автор:** Бегушева Элина  
> **Год:** 2025  
> Проект разработан в рамках проектной работы для участия в конкурсе **Junior ML Contest**.

**ShAMLock** — интеллектуальная система для борьбы с отмыванием денег (Anti-Money Laundering, AML), основанная на графовых нейронных сетях (GNN). Проект детектирует и подсвечивает подозрительные транзакции.

---

## 🚀 Ключевые возможности

- **Детекция фрода с помощью GNN**: Использование модели GraphSAGE для анализа связей между транзакциями.
- **RESTful API**: Гибкий API на базе FastAPI для интеграции и управления данными.
- **Интерактивный дашборд**: Панель управления на Streamlit для мониторинга транзакций, просмотра алертов и визуализации графов связей.
- **Графовая визуализация**: Наглядное отображение цепочек транзакций с помощью Neo4j для выявления скрытых паттернов.
- **Развертывание в Docker**: Весь стек приложения (API, БД, дашборд) запускается с помощью Docker Compose.

---

## 🛠️ Стек технологий

- **Бэкенд**: Python, FastAPI
- **Базы данных**: PostgreSQL (для транзакционных данных), Neo4j (для графовых данных)
- **Машинное обучение**: PyTorch, PyTorch Geometric (PyG), Scikit-learn
- **Фронтенд**: Streamlit
- **Оркестрация**: Docker, Docker Compose

## ⚙️ Установка и запуск

### Предварительные требования

- Установленный [Docker](https://www.docker.com/get-started/) и Docker Compose.

### Пошаговая инструкция

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ваш-логин/shamlock.git
   cd shamlock
   ```

2. **Настройте переменные окружения:**
   Создайте файл `.env` на основе примера `env.example` и заполните его данными для подключения к PostgreSQL.
   ```bash
   cp env.example .env
   ```

3. **Настройте подключение к Neo4j:**
   Создайте файл `config.json` на основе `config.example.json` и укажите данные для подключения к графовой базе.
   ```bash
   cp config.example.json config.json
   ```

4. **Запустите проект с помощью Docker Compose:**
   ```bash
   docker-compose up --build
   ```
   Эта команда соберет образы и запустит все сервисы: API, дашборд, PostgreSQL и Neo4j.
